# Project Roadmap — reconstructed 2026-08-31

**Status:** Proposed, pending approval

The original 15-task plan (`.superpowers/sdd/2026-08-09-church-attendance-app-plan/progress.md`)
was lost and is not recoverable. This roadmap reconstructs the remaining work from the codebase,
the shipped specs/plans in this directory, and decisions made on 2026-08-31. Execution is
orchestrated: each phase is broken into discrete tasks and delegated to subagents, with review
against this document.

- CSV export (plan + spec, 2026-08-17) — shipped, plus post-review hardening (`55c889f`).

## Phase 2 — Error handling UX

Today there is no `error.tsx`/`not-found.tsx` anywhere; authz failures and expected
mutation errors surface as Next's raw (and in production, masked) error screen.

- [ ] `error.tsx` boundaries: recognize `AuthzError` and redirect to the existing `/denied`
      page; friendly generic fallback otherwise.
- [ ] Convert expected failures in the settings forms (duplicate category, invalid input)
      from thrown errors to typed `{ ok: false, message }` action results rendered inline.
- [ ] Keep `CounterDialog`'s existing loud retry behavior unchanged.
- [x] Sign-out button (added 2026-08-31, shipped f8f002e): `signOut` is configured in `src/lib/auth.ts` but no
      UI calls it — there is currently no way to sign out short of clearing cookies. Add a
      "Sign out" server-action form to the dashboard header, same pattern as `SignInButton`.
      Needed for shared tablets and for switching between admin/volunteer accounts.

## Ordering and dependencies

Phase 0 tasks are independent and can run in parallel with Phase 1. Phase 1 (CRUD) is the
approved next feature. Phase 3 makes Phase 1's archived-event rule meaningful but is not a
blocker. Phases 2–4 should land before Phase 5 ships to real users.

## Standing conventions for delegated work

- Follow AGENTS.md (authz on every mutation, Zod validation, revalidatePath, soft-delete guards).
- TDD per the superpowers flow; `npm run lint && npm test && npx tsc --noEmit` must pass.
- One phase task per subagent dispatch, reviewed against this roadmap before merging.
